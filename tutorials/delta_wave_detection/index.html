Delta wave detection¶

Run this notebook from top to bottom in a Python kernel with neuro_py installed. The synthetic example runs without external data and demonstrates detection, waveform plots, interval restrictions, and a CellExplorer MAT-file round trip. The optional session section uses HMC1/day8 after you set RUN_SESSION = True.

The detector returns a pandas DataFrame. Its default save name is basename.deltaWaves.events.mat, and event_name allows custom names. Existing files are always protected. Session saving is disabled in this notebook until you explicitly enable it; the export demonstration uses a temporary folder.

%matplotlib inline

from pathlib import Path
from tempfile import TemporaryDirectory

import matplotlib.pyplot as plt
import numpy as np
from IPython.display import display

from neuro_py.detectors import detect_delta_waves, save_delta_wave_events
from neuro_py.io import loading
from neuro_py.io.matlab import load_mat

1. Create a reproducible single-channel recording¶

The sample clock is in seconds, the sampling rate is in Hz, and LFP shape is (n_samples,). Three isolated positive waves are embedded in low-amplitude noise.

fs = 250.0
sample_times = np.arange(0, 30, 1 / fs)
rng = np.random.default_rng(42)
trace = rng.normal(0, 0.1, sample_times.size)
expected_peaks = np.array([5.0, 15.0, 25.0])
for peak in expected_peaks:
    relative_time = sample_times - peak
    trace += (
        8
        * np.cos(2 * np.pi * 2.5 * relative_time)
        * np.exp(-((relative_time / 0.15) ** 2))
    )

2. Detect waves and inspect the DataFrame¶

For array input, disable session-based NREM/EMG restrictions explicitly and set save_mat=False. Artifact rejection is disabled for this known-clean simulation: its deliberately rare, large waves exceed the raw-amplitude artifact threshold. The real-session example keeps artifact rejection enabled.

Each peak/trough threshold and duration bound is a separate keyword input. Thresholds are in z units; trough thresholds are positive magnitudes of the negative final trough. Duration bounds are in seconds. The options below are also used by the optional session example. These thresholds qualify waves; boundaries remain trough-to-trough.

Firing verification is enabled by default. This simulation has no cortical spike trains, so array_options explicitly sets verify_firing=False. If verification is enabled without cortical cells with spike data, the detector warns that firing cannot be verified, retains the LFP detections, and records firing_verified=False.

detection_options = dict(
    threshold=3.0,  # Peak-to-final-trough difference in z units.
    low_peak_threshold=1.0,
    high_peak_threshold=3.0,
    low_trough_threshold=0.0,
    high_trough_threshold=1.5,
    min_duration=0.15,  # Trough-to-trough duration bounds in seconds.
    max_duration=0.65,
)

array_options = dict(
    verify_firing=False,
    **detection_options,
    lfp=trace,
    fs=fs,
    timestamps=sample_times,
    nrem_restrict=False,
    emg_threshold=np.inf,
    reject_artifacts=False,
)
events = detect_delta_waves(**array_options, save_mat=False)

Visual guide: which thresholds must a wave pass?¶

The figures below reuse detection_options, so changing the named inputs above updates the threshold lines and acceptance map when these cells are rerun. The example waveforms and firing responses are illustrations, not additional recorded events. The schematic waveforms already use standardized filtered-LFP units; the raw artifact checks use a different standardization, shown separately.

Let P be the positive peak, T the final trough (a signed z score), and S the initial trough. The detector first requires either route A or route B:

Route Peak condition Final-trough condition Default interpretation
A: high peak, shallow trough allowed P > high_peak_threshold T <= -low_trough_threshold P > 3 and T <= 0
B: lower peak, deeper trough required P >= low_peak_threshold T < -high_trough_threshold P >= 1 and T < -1.5

Every wave must also pass all of these:

  • P - T > threshold (default 3 z units); this is a vertical difference, not a threshold on P alone.
  • P > S; there is no separate amplitude threshold for the initial trough.
  • min_duration <= stop - start <= max_duration (default 0.15–0.65 s).
  • The complete wave must lie within a usable detection segment, outside edge_buffer (default 1 s) at each segment edge.

Trough inputs are positive magnitudes. Thus high_trough_threshold=1.5 draws a horizontal line at −1.5, not +1.5. Thresholds decide whether a wave qualifies; the start and stop remain the neighboring troughs, found from derivative zero crossings.

Four matching waveform examples (at the defaults): A passes route A and B passes route B. C passes route B, but its total excursion is only 2.7 z, below the required >3 z, so it is rejected. D fails both peak/trough routes and also has an insufficient 2.7 z excursion. C and D are rejected examples, rather than additional acceptance routes. Each panel reports its individual gate results and uses the same peak/trough values as its labeled map point.

Before morphology: EMG and artifact thresholds¶

These thresholds have different units and purposes from the four filtered-LFP thresholds above. The following schematics use the detector's default values.

Gate Default What it does
emg_threshold EMG < 0.6, continuously for at least 1 s Keeps low-EMG periods inside the requested/NREM epochs; EMG keeps its input units. Set np.inf to disable.
reject_artifacts amplitude check abs(raw z) > 6 Removes the affected raw samples with 0.5 s padding on both sides.
reject_artifacts difference check abs(diff(raw z)) > 10 Removes fast jumps with 0.1 s padding on both sides. This is a difference of raw-signal z scores, not a separately z-scored derivative.
edge_buffer 1 s Keeps full waves away from the start/end of each filtered usable segment, including new edges created by artifact removal.

Artifact cutoffs/padding and the minimum low-EMG duration are fixed implementation defaults; reject_artifacts=False disables both artifact checks. NREM restriction, detection_epochs, and ignore_intervals select time intervals rather than SD levels. filter_band and passband are frequency settings, not amplitude thresholds.

After morphology: default firing verification may raise threshold¶

With verify_firing=True (the default), the detector pools cortical spikes, makes a ±0.5 s PETH for each candidate in 10 ms bins, smooths it with a Gaussian of one-bin sigma, and z-scores each candidate's PETH across time. It averages that standardized response within ±50 ms of the delta peak. This firing-response z score is distinct from both raw-LFP and filtered-LFP z scores.

Candidates are sorted by decreasing amplitude = P - T. A moving mean over up to 100 candidates must be ≤ −0.5 to support a cutoff. The lowest amplitude at which that smoothed response meets the criterion becomes the proposed cutoff; the effective cutoff is max(threshold, proposed_cutoff). Events must exceed it strictly. The peak/trough thresholds and trough-based boundaries stay unchanged. The figure below illustrates this heuristic; its firing data are simulated.

The PETH window, bin size, smoothing, averaging window, moving-mean width, and −0.5 response criterion are fixed heuristic settings. This is not a significance test. Missing cortical cells or unsuccessful verification triggers a warning, retains the initial LFP detections, and records firing_verified=False.

fig, axes = plt.subplots(1, 2, figsize=(14, 4.2), layout="constrained")
peth_edges = np.linspace(-0.5, 0.5, 101)
peth_centers = (peth_edges[:-1] + peth_edges[1:]) / 2
for sign, color, label in [
    (-1, "#0f766e", "Illustrative suppression"),
    (1, "#b45309", "Illustrative peak increase"),

    smooth = ndimage.gaussian_filter1d(counts, 1.0)

)
axes[0].axhline(0, color="0.5", lw=0.8)

What to tune: use threshold to change the required total excursion, the four named peak/trough inputs to change the allowed wave shape, and min_duration / max_duration to change the allowed timescale. Use emg_threshold for the EMG restriction, edge_buffer for filtering edges, reject_artifacts to enable/disable artifact rejection, and verify_firing to enable/disable firing refinement. The effective post-verification amplitude cutoff is saved as events.attrs["detectorinfo"]["threshold"]; the requested initial settings are in events.attrs["detectorinfo"]["detectionparms"].

Optional high-gamma confirmation¶

A large slow voltage deflection can resemble a delta wave while the local network is still active. High-gamma power provides a complementary measure: a drop in this power can support the interpretation that the positive delta peak marks a cortical DOWN state with reduced population firing.

Levenstein et al. (2019), Slow wave detection combined delta peaks with suppression of 100–400 Hz power, smoothed over 80 ms and normalized within a 20 s neighborhood. Their thresholds were calibrated against spikes and they required overlapping delta and gamma events.

Our optional check adapts that idea to the existing detector. It bandpasses a user-selected gamma voltage channel, smooths its squared voltage, and computes local mean/SD z scores. An event survives only if a continuous interval at or below gamma_threshold contains the positive delta peak and occupies at least gamma_min_duration within the original trough-to-trough event. Accepted event boundaries and delta amplitudes stay unchanged. This is a confirmation step, not a reproduction of the paper's full detector: normalization is conventional mean/SD, and the exposed threshold is not automatically calibrated from spikes.

The synthetic example has three equally valid delta waveforms. Gamma is suppressed at 5 and 25 s but increases at 15 s. The gamma check should reject only the middle wave. We use 1250 Hz sampling because the default 400 Hz upper cutoff needs fs > 800; the earlier 250 Hz example cannot support that band.

from scipy import ndimage, signal

gamma_demo_fs = 1250
gamma_demo_time = np.arange(0, 30, 1 / gamma_demo_fs)
gamma_demo_rng = np.random.default_rng(818)
gamma_demo_delta = gamma_demo_rng.normal(0, 0.1, gamma_demo_time.size)
for peak in (5, 15, 25):
    relative = gamma_demo_time - peak
    gamma_demo_delta += 8 * np.cos(2 * np.pi * 2.5 * relative) * np.exp(-(relative / 0.15) ** 2)

gamma_demo_sos = signal.butter(
    4, (100, 400), btype="bandpass", fs=gamma_demo_fs, output="sos"
)
gamma_demo_voltage = signal.sosfiltfilt(
    gamma_demo_sos, gamma_demo_rng.normal(size=gamma_demo_time.size)
)
gamma_demo_envelope = np.ones(gamma_demo_time.size)
for peak in (5, 25):
    gamma_demo_envelope *= 1 - 0.99 * np.exp(-((gamma_demo_time - peak) / 0.22) ** 8)
gamma_demo_envelope += 4 * np.exp(-((gamma_demo_time - 15) / 0.22) ** 8)
gamma_demo_voltage *= gamma_demo_envelope

gamma_options = dict(
    gamma_band=(100.0, 400.0),
    gamma_threshold=0.0,       # at or below the local mean power
    gamma_smoothing=0.08,     # seconds

Follow the decision from voltage to local power¶

Each column follows the same candidate through three views. The shaded strip is the delta event's original duration; the dashed vertical line is its positive peak. # Reproduce the documented power calculation for plotting, without private APIs.
gamma_demo_filtered = signal.sosfiltfilt(gamma_demo_sos, gamma_demo_voltage)
gamma_demo_smooth_samples = 2 * int(round(gamma_options["gamma_smoothing"] * gamma_demo_fs / 2)) + 1
gamma_demo_baseline_samples = 2 * int(round(gamma_options["gamma_baseline"] * gamma_demo_fs / 2)) + 1
gamma_demo_power = ndimage.uniform_filter1d(
    gamma_demo_filtered**2, gamma_demo_smooth_samples, mode="reflect"
)
gamma_demo_power -= np.median(gamma_demo_power)
gamma_demo_mean = ndimage.uniform_filter1d(gamma_demo_power, gamma_demo_baseline_samples, mode="reflect")
gamma_demo_sd = np.sqrt(np.maximum(
    ndimage.uniform_filter1d(gamma_demo_power**2, gamma_demo_baseline_samples, mode="reflect")
    - gamma_demo_mean**2, 0,
))
gamma_demo_z = np.divide(
    gamma_demo_power - gamma_demo_mean, gamma_demo_sd,
    out=np.full_like(gamma_demo_power, np.nan), where=gamma_demo_sd > 0,
)

Choose the channel and tune the confirmation¶

For a session, pass gamma_channel=<zero-indexed cortical channel>. It may be the delta channel or a separate channel from the same cortical population. The detector reads a view of that channel from the existing LFP memmap. For arrays, use gamma_lfp=voltage with exactly the same sample count, timestamps and sampling rate as lfp; there is no implicit resampling. An optional gamma_channel then serves only as an array-channel label. Supply raw voltage, not power values.

Input Default Effect
gamma_band (100, 400) Hz Frequencies used as the activity proxy; both cutoffs must lie below Nyquist.
gamma_threshold 0.0 local SD Power must be at or below this value; negative values demand stronger suppression.
gamma_smoothing 0.08 s Power averaging window; larger windows blur brief transitions.
gamma_baseline 20.0 s Local normalization window; must exceed the smoothing window.
gamma_min_duration 0.04 s Continuous suppression within the event, containing its positive peak.

The default threshold is an exposed starting point, not a cutoff established by the paper. Check wave-triggered gamma and, when available, spikes in your own recording before choosing it. A channel with gamma power that tracks cortical firing is more useful than an arbitrary channel; line noise, muscle activity and channel location can affect this proxy. Stronger suppression requirements improve selectivity but may discard real waves with weak gamma modulation.

Both channels respect the same NREM/EMG and interval restrictions. NaNs, timestamp gaps and rejected artifacts split the data; filtering and local normalization never join across them. Missing/constant gamma voltage cannot confirm a wave. Local windows reflect at segment edges, with the configured edge buffer excluded.

Gamma confirmation runs before the independent verify_firing step, whose default remains True. Gamma does not replace the missing-cortical-cells warning. Here we disabled firing verification because the simulation has no spike trains. The metadata records all gamma settings, the source channel in both numbering conventions, and gamma_rejected (the count removed before firing refinement). No gamma source means no gamma filtering and the original behavior.

Algorithm and differences from neurocode¶

The morphology detector follows FindDeltaWaves.m: subtract a fifth-order 0.5 Hz Chebyshev-II lowpass from the raw LFP, lowpass at 9 Hz, differentiate, and lowpass the derivative at 9 Hz using order eight. Both filtering stages use forward/backward filtering with 20 dB stopband attenuation. Upward/downward/ upward derivative zero crossings identify the initial trough, positive peak, and final trough. Wave amplitudes use sample standard deviations pooled across the usable segments. The initial trough must be below the peak, and waves must last 150–650 ms. Acceptance requires either a peak above 3 SD with a nonpositive final trough, or a peak at least 1 SD with a final trough below -1.5 SD. The peak-to-final-trough difference must also exceed threshold=3.

filter_band controls morphology filtering; passband controls channel selection only. This distinction reflects what the MATLAB code actually does.

The Python implementation uses stable second-order sections at the native sampling rate. It filters each contiguous usable segment separately, excludes NaNs and artifacts instead of interpolating over them, and rejects events within edge_buffer=1 second of segment boundaries. Artifacts use the MATLAB wrapper's 6 SD amplitude and 10 SD difference criteria, with 0.5 s and 0.1 s padding. The difference threshold is in SD units of the raw signal, as in CleanLFP.m. These choices prevent events across gaps but can exclude waves retained by MATLAB. The Python sample clock starts at zero, consistent with other neuro_py loaders; the MATLAB wrapper starts at 1/fs.

Firing verification defaults to True, matching the MATLAB wrapper's executable default. It can raise the amplitude cutoff based on cortical population firing suppression. Set verify_firing=False to disable it. Supply spike_times as one seconds-based array per unit. Otherwise cortical spikes are loaded through loading.load_spikes. This heuristic uses 10 ms bins over ±0.5 s, Gaussian smoothing with sigma one bin, per-event z scores averaged over ±50 ms, and a moving mean over up to 100 amplitude-ordered events. It uses the lowest amplitude cutoff with mean suppression ≤-0.5 and never lowers the requested amplitude threshold. Missing spikes or absent suppression produce a warning and retain the LFP detections; metadata records verification as unsuccessful. No interactive debugger or channel picker runs.
